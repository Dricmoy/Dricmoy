## 🛠 Selected work

### [Lot](https://github.com/Dricmoy/lot-trading-lab) — paper-trading lab · [live](https://lot-trading-lab.vercel.app) · [try Replay](https://lot-trading-lab.vercel.app/replay)

A paper-trading platform with a React client, a **Java 21 / Spring Boot** account and replay API, and a **C++20 matching engine** with price-time priority, backed by PostgreSQL. I migrated it off the original Django and Go services with existing accounts, sessions, and saved replays preserved. It handles portfolio accounting, idempotent retries, partial fills, resting limit orders, and account isolation.

`React` `TypeScript` `Java` `Spring Boot` `C++20` `PostgreSQL` `OCI`

### [DriveLab](https://github.com/Dricmoy/drivelab) — autonomous-driving workbench

A driving planner and visual replay workbench comparing route following with receding-horizon trajectory planning.

`React` `Three.js` `Python` `Rust` `PyTorch`
